# Changelog

## 2.0.0 — Industry Example Release

- Preserved Option A model builder and Option B direct QUBO / Ising input from 1.2.0.
- Preserved PUBO host-side quadratization and the N=512 / N=1024 UART host adapters.
- Added 30 website-aligned industry-domain folders under Engineering, Medical, Finance and Others.
- Added 41 industry examples and four getting-started examples, plus legacy compatibility demos.
- Added a central example runner with explicit CPU mock or FPGA backend selection.
- Added example catalogue, per-domain READMEs, modelling boundaries and updated publishing instructions.
- Added a smoke test that executes all runnable examples using the CPU mock backend.
